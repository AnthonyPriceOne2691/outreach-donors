# Spec: модуль «Продажи», срез 1.3 — загрузка базы лидов из CSV и Google-таблицы

## Problem

Базы лидов приходят файлом или Google-таблицей, и колонки у них разные: «Почта»,
«E-mail», «Work email»; где-то нет сайта компании, где-то нет заголовка.
Многоколоночного загрузчика в outreach-donors нет. `contacts.file_sweep` берёт
одну колонку хостов, а плохие ячейки только считает. Лиду продаж нужны адрес,
имя, должность, компания, страна и язык, а ещё домен компании: по нему потом
работают стоп-лист и дубли с другими направлениями.

## Users / stakeholders

- Владелец и оператор: загружают базу гипотезы — консолью сейчас, мастером
  экрана в срезе 1.5.
- Срез 1.4 (очистка): стоит на загруженных лидах и их домене компании.
- Потоки доноров: строки `contacts` загрузка не заводит (решение (а) от 01.10).

## In scope

- Чтение — общий `contacts.sweep_input.read_records`. Он даёт разделители
  `, ; \t |`, снятый BOM (utf-8-sig), номера строк файла и отказ словами на файл
  не в UTF-8. Байты с экрана и из Google проходят через временный файл.
- Google-таблица по ссылке: CSV-экспорт листа (`…/export?format=csv&gid=…`)
  через `httpx`, без новой зависимости. Запрос уходит только на
  `docs.google.com`, по адресу, собранному из номера таблицы.
- Сопоставление колонок: таблица синонимов RU/EN данными и правка руками. Файл
  без заголовка — предложение сопоставить руками.
- Нормализация:
  - почта — нижний регистр, без пробелов;
  - домен компании — из колонки сайта, иначе из домена рабочей почты;
  - бесплатная почта — только вместе с сайтом;
  - страна и язык — коды;
  - текст — по ширине колонки.
- Отчёт по каждой строке: номер строки файла, причина словами, ячейка как есть.
  Загрузка не останавливается на плохой строке.
- Предпросмотр (сухой прогон) и загрузка: API под `Permission.SALES` и команда
  `outreach sales-import`.
- Журнал: `AuditAction.SALES_LEADS_IMPORTED` и миграция `auditaction`.

## Out of scope

- Очистка против базы, дубли, стоп-лист, проверка адресов — срез 1.4.
- Экран и мастер загрузки — срез 1.5.
- XLSX: нужна зависимость, предлагать при надобности.
- Закрытые таблицы через сервисную учётку Google: ключи и зависимость ради
  одного чтения.
- Страна словом («Germany», «Германия») и часовой пояс лида — срез 1.4.

## Acceptance (observable)

- [ ] CSV с «;» и русскими заголовками сопоставляется сам.
- [ ] Плохая строка — строка отчёта с номером, причиной и ячейкой; остальные
      строки загружаются.
- [ ] Бесплатная почта без сайта — отказ строки; рабочая почта даёт домен.
- [ ] Закрытая таблица по ссылке — отказ словами, а не пустой список.
- [ ] Файл без заголовка — предложение сопоставить руками, а не «0 лидов».
- [ ] 5000 строк — предпросмотр за секунды, без записи в базу.
- [ ] Загрузка пишет лидов только в `sales_leads`: `contacts` не трогается,
      журнал называет автора и источник.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| A1 | CSV `;`, колонки «Почта; Имя; Компания; Сайт» | 4 поля сопоставлены сами, лиды в предпросмотре |
| A2 | строка без почты | в отчёте «строка 7: нет адреса», остальные загружены |
| A3 | `ivan@gmail.com` без колонки сайта | отказ строки «нет сайта компании» |
| A4 | `ivan@acme.com` без колонки сайта | домен `acme.com` из почты |
| A5 | ссылка на закрытую Google-таблицу | отказ словами «таблица не открыта по ссылке — откройте доступ или загрузите CSV», а не пустой список |
| A6 | файл без строки заголовка | предложено ручное сопоставление, а не «0 лидов» |
| A7 | 5 000 строк | предпросмотр за секунды, без записи в базу |
| A8 | загрузка в гипотезу | лиды в `sales_leads`, `contact_id` пуст, строк `contacts` нет; журнал `sales_leads_imported` с автором, источником и числами |
| A9 | ссылка на таблицу, а Google не ответил (сеть, 429, 5xx) | отказ «Google не ответил — повторите позже или загрузите CSV», а не «таблица закрыта» (ошибочный вход) |

A1–A7 — из плана фазы Ф1. A8 и A9 выведены из того же плана: A8 — из решения (а)
от 01.10, A9 — из правила «провайдер не ответил» и «нет доступа» — разные исходы
(`okf/provider-refusals.md`).

## Non-functional

- Предпросмотр базы не касается: в нём нет сессии.
- Плохая строка стоит строки, а не загрузки. Поле, которое разрешено не знать,
  стоит не дороже пустого (урок L67 соседнего проекта).
- Отказ всего источника — 400 со словами сервера; Google не ответил — 502.
- Миграция только добавляет значение перечисления; данные не трогает.
- Файлы ≤ 500 строк; `except` не молчит; окружение читает только `config/`.

## Open questions

- Заголовок с незнакомыми именами колонок не узнаётся. Первая строка тогда
  читается как данные и видна в отчёте: «строка 1: не адрес почты». Флаг
  «первая строка — заголовок» есть в API и консоли. Мастеру 1.5 — показать его.
