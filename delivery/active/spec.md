# Spec: контур модуля «Продажи», волна В0 — непреложное модуля и проверка волн

## Problem

Модуль «Продажи» начинает жить в этом репозитории. Он наследует контур
(delivery, гейты, CI), но не его полноту. Волны контура легко пропустить:
- граница модуля;
- поведение модели на каждом промпте;
- минимум эксплуатации;
- понятия OKF.

Правило «помнить про волну» не исполняется. Урок этого же репозитория: правило
публичного репозитория продержалось ровно до первого среза, который его не
помнил (`scripts/gates.py`, `check_public_repo`). Нужны записанное непреложное
модуля и механизм, который не пускает в main срез продаж с пропущенной волной.

## Users / stakeholders

- Агенты и инженер, делающие срезы продаж: проверка называет волну и что делать.
- Срезы доноров: их PR проверка не меняет — без `backend/features/sales/` она
  зелёная.
- Владелец репозитория: подписи необратимого и решения по волнам.

## In scope

- Раздел «Продажи» в `delivery/CONSTITUTION.md` — восемь правил модуля.
- Реестр волн `delivery/contour-waves.md`.
- Проверка `scripts/contour_waves.py` с тестами и обратными прогонами.
- Подключение: pre-push — предупреждение, CI — красный.
- Строка проектного гейта в карте ролей `delivery/STACK-ACCEPTANCE.md`.
- Архив прежнего активного среза `front-polish`: канон допускает один
  `delivery/active`.

## Out of scope

- Код продаж.
- Догон канона — волна В-обн, отдельным срезом.
- Понятия OKF — волна В2.
- Правка канонных скриптов. Дефект канона — заявка `kind: upstream-candidate`
  в `scripts/lint/adapted.json` по протоколу сети проектов.

## Acceptance (observable)

- [ ] Без файлов `sales/` проверка зелёная и печатает «продаж в дереве нет —
      судить нечего». Это сказано словами, а не молчанием.
- [ ] Каждое нарушение из таблицы примеров краснеет в CI и сообщает, что делать.
- [ ] На pre-push те же нарушения — предупреждение, пуш проходит.
- [ ] У доктора DEAD 0, `delivery_check` — 0 errors, `check_gate_coverage.sh` OK.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| A1 | дерево без `backend/features/sales/` | exit 0; все волны `pending`; строка «продаж в дереве нет — судить нечего» |
| A2 | PR приносит `backend/features/sales/__init__.py`, В0 в реестре `pending` | CI: exit 1, «В0: в дереве есть backend/features/sales/, волна не развёрнута — разверни или запиши weak/absent/n/a reason=…» |
| A3 | то же, режим pre-push (`--warn`) | exit 0, то же сообщение с пометкой «предупреждение» |
| A4 | В1 `pending`; в базе PR (`origin/main`) `sales/` ещё нет | exit 0, «В1: триггер сработал, предел — следующий PR продаж» |
| A5 | В1 `pending`; в базе PR `sales/` уже есть | CI: exit 1 |
| A6 | в `sales/prompts/` лежит `reply_kind.md`; В3 `deployed`, но файл не назван в `model_surface` STATUS | CI: exit 1, «промпт reply_kind.md не назван в model_surface» |
| A7 | строка реестра `absent` без `reason=` | CI: exit 1 (граничный случай записи) |
| A8 | `sales/` есть, файла реестра нет | CI: exit 1, «реестр волн не найден» |
| A9 | `stack-selftest:` нет ни в STACK-ACCEPTANCE, ни в STATUS | CI: exit 1 |
| A10 | срез `sales-*`, в его `tasks.md` нет раздела «Уроки» | CI: exit 1 |
| A11 | рядом лежит `~/Documents/Prepare`, его версии выше записи в STACK-ACCEPTANCE | pre-push: предупреждение «канон впереди: …»; в CI строки нет |
| A12 | реестр битый (лишняя колонка, неизвестное состояние) | exit 1, «реестр не разобран: строка N» — не «волн нет» (ошибочный вход) |
| A13 | срез `sales-*` правит `backend/features/letters/sending.py`, а строки `shared_changes:` в STATUS нет | CI: exit 1, «общий код тронут без объявления: letters/sending.py — объяви shared_changes и с кем согласовано» |

## Non-functional

- Только стандартная библиотека: шаг CI идёт до установки зависимостей, хук
  pre-push — и без `.venv`.
- Файл проверки не длиннее 500 строк, окружение не читается, `except` не молчит.
- Секунды, а не минуты: несколько файлов и два вопроса к git.

## Open questions

- Детекторы автоотправки, порогов агента, промптов агента и судьи сегмента
  назовут их срезы. До тех пор эти волны судит человек, и проверка печатает
  это словами.
