# Spec: модуль «Продажи», срез 1.5 — часть 1 из 2 (1.5a): списки раздела на сервере

**Problem.** Лиды продаж загружались и чистились только командами: увидеть базу гипотезы,
понять, сколько готово к письмам и почему отсеяно остальное, было негде. Раздел «Продажи»
на экране (часть 2) читает списки, которые даёт эта часть.

## In scope

- `GET /api/sales/hypotheses` — гипотезы со счётчиками лидов по состояниям (одним запросом).
- `GET /api/sales/leads` — лиды с фильтрами `state`, `reason`, `hypothesis`, `search`,
  новейшие первыми, страница номером, размер страницы называет сервер (20, предел 100);
  сводка по всем лидам (`states`) и полный перечень кодов причин (`reasons`).
- Под `Permission.SALES`: без права — 403 словами (A4); негодное состояние — 422;
  незнакомый код причины ничего не находит, а не падает.

## Out of scope

Экран, меню, вкладки, мастер загрузки, клиент и подписи, замеры — часть 1.5b. Заведение
гипотезы и очистка с экрана — команды консоли.

## Acceptance examples

Примеры среза 1.5 — для двух частей; эта часть закрывает серверную сторону A2 и A4.

| # | Вход | Ожидаемый выход | Часть |
|---|---|---|---|
| A1 | файл с тремя плохими строками через мастер | «Загружено 97, отклонено 3.» и причины словами | 1.5b |
| A2 | фильтр «отклонённые: дубль» | сервер отдаёт только `rejected` с причиной `duplicate` по именам `state` и `reason`; экран держит их в адресе `?state=rejected&reason=duplicate`, перезагрузка сохраняет | сервер — 1.5a, адрес — 1.5b |
| A3 | обе темы, 1440 и 390 px | контраст не ниже 4,5 (крупный — 3,0); таблицы прокручиваются, рамка цела | 1.5b |
| A4 | пользователь без права `sales` | сервер — 403 словами; на экране пункта нет, прямой адрес — «раздел недоступен» | сервер — 1.5a, экран — 1.5b |
