# Spec: модуль «Продажи», срез 1.4 — часть 1 из 2 (1.4a): страна и часовой пояс лида

**Problem.** Отправка (Ф4) идёт только в рабочие часы получателя, а база приходит со страной
словом («Германия», «Germany», «USA») и без часового пояса. До этой части страна словом
записывалась пустой с замечанием, пояса у лида не было.

## In scope

- Страна — кодом ISO-2 по таблице названий RU/EN и псевдонимов (данными, не ветками кода).
- Часовой пояс — из колонки файла (`LeadField.TIMEZONE`, синонимы RU/EN), иначе по стране:
  у страны с одним поясом — он; у страны с несколькими — пояс столицы с замечанием «в файле
  не задан» (решение владельца 04.10, для всех таких стран); без столицы — пусто.
- Непонятые страна или пояс строку не роняют: лид загружается, замечание — в отчёте (L67).

## Out of scope

Правила очистки, стоп-лист, проверка адресов, расход, `outreach sales-clean` — часть 1.4b+c.
Экран — 1.5. Порог по поясу при отправке — Ф4.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| A1 | страна «Германия» или «Germany», пояса в файле нет | `de`, `Europe/Berlin`, замечаний нет |
| A2 | страна «USA», пояса в файле нет | `us`, `America/New_York`, замечание «часовой пояс по столице — America/New_York: у страны us их несколько, в файле не задан» |
| A3 | колонка пояса в файле задана | пояс из колонки, страна его не перебивает |
| A4 | страна или пояс непонятны | лид загружен, поле пусто, замечание в отчёте строки; таблица: 249 кодов, каждый пояс есть в базе поясов |
