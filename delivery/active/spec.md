# Spec: срез 5.1 `sales-approval`, части «А», «Б» и «В» одним PR — решения по черновику агента в переписке

## Problem

Черновики агента (шов) видны только API: человек не видит, что агент предложил, и не может отправить, поправить или
отклонить черновик из переписки. Черновик написан на один ответ собеседника; пока он ждёт человека, переписка может
уйти дальше — шов отправлял такой черновик как ни в чём не бывало. Соседняя сессия одобрила экран черновика (5.1) с
обязательным условием: проверка «черновик устарел» — на сервере, 409. «Как есть» у отданного человеку был закрыт
только для запроса без текста (тот же текст правкой уходил); экран настроек агента знал этапы своим списком; а
выбранный раньше автопилот при снятом выключателе выглядел работающим, хотя черновики ждут человека. Три части —
одним PR (решение владельца: не гонять CI на каждый мелкий PR).

## In scope

- **А (сервер шва).**
  - 409 «черновик устарел» в `send_draft` — и для «как есть», и для правки: после `based_on` (ответа черновика) в
    переписке есть новое письмо собеседника (ответ или отписка) или наше письмо (на этот ответ или позже, или
    ушедшее позже него).
  - 409 у `escalated` и для правки прежним текстом (после обрезки пробелов).
  - `AgentStage.title`, `lead`, `reject_reasons` (общий список по умолчанию); в API — `AgentStageView.title`, `lead`,
    `price_side`; `ThreadView.agent_reasons`; `DraftCard.verdict`, `attempts`.
  - `AgentStageView.autopilot_refusal` — почему автопилот этапа не действует (слова `autopilot.refusal`) рядом с
    `autopilot_allowed`.
- **Б (экран).**
  - `AgentDraftBanner` (`frontend/src/agent/`) — над `AnswerBox` в `ThreadPage.tsx` (импорт и одна строка): последний
    черновик переписки, общий для любого этапа.
  - Решения: как есть, с правкой, отклонить с причиной (список этапа или «другое» словами); «ответ не нужен» —
    строкой с «Ответить всё же».
  - Подсказка у поля ответа при готовом черновике; ручной ответ не запрещён.
  - Экран настроек агента — этапы, пояснения и подпись предела по реестру сервера.
- **В (экран).**
  - Предупреждение «Автопилот выбран, но письма сами не уходят» и слова сервера, почему, — при режиме `autopilot` и
    `autopilot_allowed: false`; при действующем автопилоте — ничего.

## Out of scope

- **А:** причины отклонения и строка этапа продаж (своим срезом); ручной ответ из переписки не запрещается и проверку
  «устарел» не проходит — человек отвечает, видя переписку.
- **Б:** проверка «черновик устарел» на экране (её держит сервер, часть «А»), список «ждут человека», «написать
  заново» на плашке.
- **В:** переключатель режима на экране; общее правило цвета заголовков `Alert`.
