# Spec: модуль «Продажи», срез 1.5 — часть 2 из 2 (1.5b): раздел на экране

**Problem.** Лиды продаж загружались и чистились только командами; увидеть базу гипотезы,
понять, сколько готово к письмам и почему отсеяно остальное, загрузить файл без консоли —
было негде. Раздел «Продажи» на экране закрывает это: гипотезы со счётчиками, лиды с
фильтрами под колонками, мастер загрузки с отчётом по каждой строке до записи.

## In scope

Часть 1 (слита): списки на сервере — первый пункт ниже. Эта часть — остальное.

- **Списки под правом `sales`** (`backend/api/sales/routes.py`, дополнено, не переписано):
  `GET /api/sales/hypotheses` — гипотезы со счётчиками лидов по состояниям;
  `GET /api/sales/leads` — лиды с фильтрами `state`, `reason`, `hypothesis`, `search`,
  страница номером, размер страницы называет сервер (`limit`, 20); сводка по всем лидам
  (`states`, `reasons` — полный перечень кодов). Без права — 403 словами (A4).
  Логика чтения — `backend/features/sales/browse.py`.
- **Пункт меню «Продажи»** (`Shell.tsx`, `SECTIONS`) под правом `sales`; маршруты `/sales`
  и `/sales/import` под `RequireAccess permission="sales"`: без права пункта нет, прямой
  адрес — «Раздел недоступен … «раздел продаж» не выдано» (A4), к серверу продаж не ходит.
- **Вкладки «Лиды» и «Гипотезы»** (`frontend/src/sales/`): сводка плитками по всем лидам,
  таблица лидов с фильтрами под колонками (поиск, гипотеза, состояние, причина — список
  причин из ответа сервера), по 20, фильтры и страница в адресе —
  `?state=rejected&reason=duplicate` переживает перезагрузку (A2); гипотезы — таблица
  со счётчиками-ссылками на лидов под тем же фильтром.
- **Мастер загрузки** `/sales/import`: гипотеза и источник (файл CSV или ссылка на
  Google-таблицу) → колонки файла с первыми значениями и полем лида у каждой (угадано
  сервером, правится руками; поле у колонки одно; переключатель «первая строка —
  заголовок») → отчёт: «строк в файле / станут лидами / отклонено / с замечанием», первые
  лиды, таблица «Отчёт по строкам» (строка отклонена — или загружена с замечанием) →
  загрузка. Итог «Загружено 97, отклонено 3.» и причины по группам, частые первыми,
  с номерами строк (A1); «К лидам» с фильтром по гипотезе; «Загрузить ещё».
  API — 1.3c (`backend/api/sales/schemas.py`), сервер между шагами ничего не помнит.
- **Клиент** `frontend/src/api/sales.ts` (форма `multipart/form-data` своим `fetch`:
  общий `request` умеет только JSON, `client.ts` — вне точек среза); типы
  `api/salesTypes.ts`, подписи `api/salesLabels.ts` — своими файлами (см. decisions).
- **Снимок прав** `frontend/src/test/fixtures.ts` (у ADMIN и OPERATOR есть `sales`);
  строка продаж в таблице ролей `docs/WEB_LAYER.md`.
- **Замеры:** `scripts/ui_screens_sales.py` (шесть экранов), подключение в
  `ui_screens.py`, пути продаж в `ui_hover.py`; запись в `docs/UI_RULES.md`.

## Out of scope

Воронка (Ф5), база знаний (Ф3); заведение гипотезы с экрана (описание — коммерческий
текст, живёт данными в базе, заводится командой); очистка с экрана (команда
`sales-clean`); разделитель CSV руками (есть в API и консоли, на экране — при первом
настоящем файле с неугаданным разделителем); XLSX; общее правило для контурных значков
в `glass.css` (находка, отдельная правка).
