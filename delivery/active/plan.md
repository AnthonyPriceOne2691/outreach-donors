# Plan: шов агента переписки, часть «А3» — решения по черновику — отправить как есть, с правкой, отклонить с причиной

## Approach

- `drafts.one`/`waiting` — черновик с версией настроек и перепиской одним запросом; `send_draft(body=None)` —
  как есть (у `escalated` и без текста — `DraftDecisionError`), `body` — с правкой; отправка `answer_reply`, затем
  `settle_sent` (статус `sent`, `final_body`, `edited`, `sent_message_id`, `decided_by/at`, журнал).
- `reject_draft` — причина обязательна (схема и функция), статус `rejected`, журнал.
- Право: смотреть — view, решать — send.

## Rejected alternatives

- Решения только на экране — отклонено, потому что интерфейс требует 422/409 на сервере.
- Три значения журнала (отправлен, с правкой, отклонён) — отклонено, потому что решение одно, детали — в `details`.

## Risks

- `answer_reply` коммитит письмо-ответ до отправки; отказ отправки оставляет письмо `queued`, черновик — нерешённым
  (тот же путь, что у человека; повторное «отправить» берёт то же письмо по ключу).
- Соседняя сессия правит отправку очередью (`features/letters`), не `answers.py`; сигнатура `answer_reply` — точка пересечения.
