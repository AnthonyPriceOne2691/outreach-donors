# Plan: срез 4.6b (модульная часть) и срез 5.4 одним PR — перенос на голову стопки

## Approach

Обе части написаны раньше базы и переносятся на её голову cherry-pick'ом по порядку, конфликты — по смыслу; что база
уже сделала иначе — берётся база (decisions). Своей отправки, добивок, балансировщика и кнопки пачки у продаж нет:
модуль отвечает общей почте через мост `core/stages.py` по его договору.

**Часть 4.6b — модуль продаж.**

  перечень команд консоли (`sales-queue` рядом с отказом этапа `FAILURES` и командой chat id бота), реестр моделей,
  заголовок `sales/models.py`, очистка лидов (`OTHER_DIRECTIONS` Ф2 вместо своей правки), снимок сложности.

  поломкой модуля); ответы читают базу и не коммитят — мост держит их в своей точке сохранения.

- **Миграция** `fa927869a835` — уже после головы базы `a9e76c0eb5b0`, голова одна; отметки времени без помощника,
  общего с миграцией передачи (гейт дублей).

## Rejected alternatives

- Своя кнопка пачки продаж — отклонено, потому что пачка общая на `Stage` с #219, на экране один путь; своя копия разошлась бы
  с общей (гейт дублей и счёт «что уйдёт»).
- Причина экрана без приставки «Ждёт человека:» — отклонено, потому что экран — путь соседней сессии (`threads/ThreadPage.tsx`),
  а приставка общая для всех причин; поправлена причина продаж (одна строка `replies/outcome.py`).
- Тест 1.1b `test_a4` — только с модулем или только без него — отклонено, потому что смысл теста двойной (срок цел у обоих, вслух
  — только когда модуля нет), параметр держит оба.
- Окно в мире тестов по умолчанию (пн–пт 9–17) — отклонено, потому что пачка и экран писем берут настоящие часы, тесты стали бы
  зависеть от часа прогона; окно проверяется своими тестами со своими часами.
- Сборка очереди в очереди задач `sales` Ф2 — отклонено, потому что та очередь — для ответов лида, чтобы они не ждали долгих задач,
  а сборка — минуты модели, как сборка писем доноров; осталась в общей `runs`, как передача 5.3.
- Перенести временные копии Ф2 из ветки 5.4 — отклонено, потому что Ф2 в базе, копии ушли бы вторым кодом.

## Риски

- Новая поверхность необратимого — письма продаж живым людям; переподпись владельцем до первой отправки продаж.
- С регистрацией модуля сторож почты 4.5b следит за ящиками продаж (`watch=True` в политике продаж): при выключенных
  продажах и ушедших письмах добивки ждут, и «ящик молчит» может подняться — находка, решение владельцу.
- Разбор ответа «хочет говорить» в базе ещё не зовёт `handoff.start`: передача лида и остановка цепочки по ней
  сработают, когда провод 5.3 ↔ Ф2 будет в main.
- Отказ общей кнопки пачки при неподключённых продажах — «продажи к почте ещё не подключены» без перечня (мост
  `check_connected`); перечень говорит вкладка «Очередь писем».
