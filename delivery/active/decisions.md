# Decisions

Одна строка на выбор: **что выбрано**, **вместо чего**, **потому что**. Часть 1.4a — страна и пояс.

- 2026-10-03 · выбрал таблицу стран данными (249 кодов ISO-2, названия RU/EN, псевдонимы) и правило «пояс по стране только у страны с одним поясом» (Китай — по закону один; Украина — без зоны Крыма) вместо столичного наугад — потому что так решил владелец 03.10; Испания и Португалия остались без пояса (Канары, Азоры) — вопрос ушёл владельцу
- 2026-10-04 · **решение владельца (через координатора):** у страны с несколькими поясами (Испания, Португалия и подобные) — пояс столицы (`geo.CAPITAL_ZONES`: Europe/Madrid, Europe/Lisbon, America/New_York, Europe/Moscow…), а не пусто; замечание в отчёте строки остаётся — «часовой пояс по столице — <пояс>: у страны <код> их несколько, в файле не задан» — потому что пустой пояс оставил бы лида без окна отправки, а колонка файла всё равно побеждает. Без столицы (Антарктида, необитаемые острова) пояс пуст с прежним замечанием. Прочтение «и подобные» — все страны с несколькими поясами, не только островные; если владелец имел в виду уже, список `CAPITAL_ZONES` сужается строками
- 2026-10-03 · выбрал колонку пояса файла поверх страны, непонятую колонку — замечание и пояс по стране — потому что колонка точнее страны (у США четыре пояса), а непонятое поле строки не стоит (урок L67)
- 2026-10-04 · решение владельца: срез сливается двумя PR — 1.4a страна и пояс (без общего кода) и 1.4b+c правила, стоп-лист, проверяльщик, расход и консоль одним PR под вейвер владельца (`max_loc_diff`), вместо трёх — потому что 1.4b без 1.4c роняет живой проверяльщик после оплаченной проверки (`UnknownOperationError`), а 1.4b сам больше 800 строк
- 2026-10-04 · решение владельца: столичный пояс — для всех стран с несколькими поясами (США, Россия, Канада, Австралия и др.), не только островных; всегда с замечанием в отчёте строки; колонка файла побеждает
