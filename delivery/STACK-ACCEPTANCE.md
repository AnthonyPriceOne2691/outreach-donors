## Карта ролей гейтов

**Две даты в шапке обязательны, и они не украшение.** Согласованность заявлений с
механикой сверяет мета-гейт (CQG `cqg@1.70`), но половина этого документа
негейтируема по природе — «полнота, не только зелёность» и разбор слепых пятен
пишутся руками и потому деградируют первыми. `checked_at:` — когда карту читали
глазами, `stale_after:` — до какой даты запись годна; семантика ровно как у
`stale_after` в OKF §7.2, вторую механику свежести не заводим. Просрочка
печатается **advisory** (○), поставку не останавливает: повод перечитать, а не
повод переписать документ ради зелёного.

Заполняется по CQG «Применимость → Карта ролей». Инвариант — **роль**, не имя файла:
если роль занял другой скрипт (другой язык / технологический стек), это фиксируется здесь, иначе
таблица CQG §3 и репозиторий расходятся молча.

## Полнота, не только зелёность

- [ ] `check_gate_coverage.sh` — OK (все гейты подключены)
- [ ] `pre-commit run --all-files` — зелено
- [ ] `stack_selftest.py` — OK (или причина, почему неприменим)
- [ ] Каждый гейт в выводе показал непустое число просканированных файлов Одно законное исключение: у правила, выбирающего файлы по имени нарушителя (`no-grab-bag-module`), пустая выборка — норма, и строка закрывается как `n/a (выборка законно пуста: <правило>)` — CQG §6.
