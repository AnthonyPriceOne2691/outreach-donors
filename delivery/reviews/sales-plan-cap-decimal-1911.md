## Ревью рисковых мест

- поле окна «Загрузить план работ»: `NumberField` хранит набранное само (`useState`), наверх отдаёт число или `null`. Начальное значение берётся из `choice` один раз, при появлении поля. Снаружи окно `choice` не меняет: закрыл окно — поля появятся заново.
- разбор строки: `numberOf` переводит строки Mantine в число («0.», «1.0», «0.50»); пустое, «-» и «.» дают `null`, как прежде пустое поле. Запятую поле само пишет точкой («0,5» → «0.5»). Уходя из поля, Mantine приводит строку к числу (`trimLeadingZeroesOnBlur`): «1.0» → «1», отрицательное прижимается к `min` — «0».
- отпечаток превью (`checkKey`) по-прежнему считается по числам `choice`: «1» → «1.0» превью не устаревает, «1» → «1.5» — устаревает, как прежде.
- «Общая цель» — то же поле. Целое Mantine отдаёт числом, строкой — только пустое и «-»; разделитель тысяч — только показ, наверх уходит число.
- что может удивить: в поле, из которого ушёл фокус, — число Mantine («0.50» → «0.5»), а не набранное; знаков после точки — два (`decimalScale`), третий поле не берёт.
