## Ревью рисковых мест

- цепочка гейтов: `scripts/lint/check_deps_audit.sh` больше не снимается строкой `deps_audit_waiver` без списка находок; приговор — в части `scripts/lint/deps_audit_verdict.py` (`read_waiver`, `NpmTree.roots`, `judge_js`, `judge_python`). Главный риск — ложное красное на каждом PR. На дереве 20.11 гейт зелёный: npm — 7 moderate от minimatch в пределах снимка `js_total=24`, critical/high нет (GHSA-fc5q-39xc-vjpf GitHub отозвал 18.11), python по `uv.lock` — 0 находок; строка старого формата в STATUS даёт только заметку. Ложное зелёное держит `tests/test_deps_audit_gate.py` (обратный прогон: прежний гейт валит 18 тестов из 29). Хук `deps-audit` в `.pre-commit-config.yaml` остался `stages: [manual]` — нарезка `_hook_stages` доктора по-прежнему видит его мимо коммит-стадии; изменение гейта объявлено в `scripts/lint/adapted.json`, доктор: DEAD 0.
- безопасность: права джоб (`permissions`) не меняются — `test_the_ci_token_only_reads` зелёный; у джобы `docker` checkout с `persist-credentials: false`: токен с правом публикации образов не лежит в `.git/config` рядом со сторонним `aquasecurity/trivy-action`. Слово `secret` — только в комментариях об инциденте 19.03.2026. Действие закреплено коммитом неизменяемого релиза v0.36.0, свои зависимости (setup-trivy, actions/cache) оно держит коммитами само.
- транзакция БД: `commit` — коммиты действий в workflow и слово в комментариях; транзакций базы дифф не трогает, риска нет.
- производительность: `json.loads` и `json.dumps`, `re.compile` и `re.search` — разбор ответов pip-audit и npm audit один раз за прогон гейта и образцы в тестах; `NpmTree.roots` обходит граф уязвимых пакетов, а их десятки. Горячего пути нет.
