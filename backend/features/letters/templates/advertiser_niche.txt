# Оффер бизнесу ниши из выдачи прогона. Этап 2, аудитория `niche`.
#
# Боевой текст: предложен по ТЗ, утверждён Anthony 12.10.2026. Смысл тот же,
# что у оффера по найденной ссылке: «разместиться можно дешевле, приходите
# к нам», — но без ссылки: пример нашей площадки и тема. Тон и длина —
# как у письма донору (price_request.txt, боевой текст 23.09.2026).
#
# Кому: сайту, который сам продаёт в нише прогона (судья: «продаёт своё»;
# `crawl/niche.py`). Его ссылки на наших донорах мы НЕ видели — поэтому ни
# «вашего размещения», ни страницы с анкором в письме нет и быть не может.
# Предлагаем другое: статью со ссылкой на сайтах его темы, которые мы ведём.
#
# ЧЕГО В ЭТОМ ПИСЬМЕ БЫТЬ НЕ ДОЛЖНО — как и в оффере по ссылке:
# 1. Цены — ни нашей, ни донора: цену называет человек в переписке.
# 2. Метрик Ahrefs — правило самого Ahrefs, нарушение бьёт по ключу.
# 3. Обещаний про площадку сверх того, что мы о ней знаем: тема и страна
#    аудитории — да, остальное — догадка.
#
# Подстановки:
#   {{example_host}}   — пример нашей площадки: принятый донор того же
#                        прогона со свежей ценой
#   {{niche}}          — тема: ключи, по которым бизнес нашёлся в выдаче
#   {{donor_audience}} — фраза про аудиторию с точкой и пробелом, пустая,
#                        когда страна неизвестна
# Все три стоят в неизменяемой зоне `offer` (`template.NICHE`): модель их не
# видит и выбросить не может.

subject: Sponsored articles on {{niche}} sites

[ask] rewrite

[terms] fixed
